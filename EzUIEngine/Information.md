This project aims to provide a simple yet extensible and complete library to elaborate an UI. Specifically, this
library's functions are:

- Control inputs (OS-independant: Windows, Linux, ...)
- Create, delete and manage widgets.
- Expose predefined widgets of the API.
- Use a generic backend (will be replaced in a future by another library called EzRenderingBackend) to handle
  everything. At the time of creating the project ImGui will be used to test the design of the UI.
